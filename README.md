# goit-ds-hw-06

---

### Концептуальна база: Лінійна регресія (Linear Regression)

**Мета:** Знайти найкращу гіперплощину $h(x)$ у просторі ознак, яка мінімізує середньоквадратичну похибку між прогнозованими та фактичними значеннями.

---

#### 1. Гіпотеза функції лінійної регресії (Векторний підхід)

Лінійна модель передбачає, що залежна змінна $y$ є лінійною комбінацією незалежних ознак $\vec{x}$. Для зручності у векторній обробці завжди додаємо _інтерсепт_ (зсув $w_0$), призначений для $x_0=1$.

**A. Формула для одного зразка:**
Якщо $\vec{x}^{(i)} = [1, x_{1}^{(i)}, \dots, x_{n}^{(i)}]$ — вектор ознак для $i$-го зразка, а $\vec{w} = [w_0, w_1, \dots, w_n]^T$ — вектор ваг:
$$h(x^{(i)}) = \vec{w}^T \vec{x}^{(i)} = w_0 + w_1 x_{1}^{(i)} + \dots + w_n x_{n}^{(i)}$$

**B. Векторна реалізація (для всього датасету $X$ та $\vec{y}$):**

- Матриця ознак: $X$ ($m$ рядків, $n+1$ стовпців).
- Вектор ваг: $\vec{w}$ ($(n+1) \times 1$).
- Вектор фактичних значень: $\vec{y}$ ($m \times 1$).

Прогнозований вектор значень ($\hat{\vec{y}}$) обчислюється наступним чином:
$$\hat{\vec{y}} = X\vec{w}$$

---

#### 2. Функція втрат (Cost Function): Середньоквадратична похибка (MSE)

Ми мінімізуємо функцію $J(\vec{w})$, яка вимірює середню квадратну відстань між $\hat{\vec{y}}$ та $\vec{y}$.

**A. Скалярна форма:**
$$J(\vec{w}) = \frac{1}{2m} \sum_{i=1}^{m} (\hat{y}^{(i)} - y^{(i)})^2$$

**B. Векторна (компактна) форма:**
$$J(\vec{w}) = \frac{1}{2m} (\underbrace{X\vec{w}}_{\hat{\vec{y}}} - \vec{y})^T (\underbrace{X\vec{w}}_{\hat{\vec{y}}} - \vec{y})$$

---

#### 3. Оновлення параметрів $\vec{w}$

Для знаходження оптимальних ваг ми використовуємо два основні методи:

**A. Градієнтний спуск (Gradient Descent):**
Це ітеративний метод, який коригує ваги $\vec{w}$ у напрямку мінімуму функції $J(\vec{w})$.

1.  **Обчислення градієнта $\nabla J(\vec{w})$:**
    $$\nabla J(\vec{w}) = \frac{\partial J}{\partial \vec{w}} = \frac{1}{m} X^T (X\vec{w} - \vec{y})$$

2.  **Крок оновлення ваг $\vec{w}$:**
    $$\vec{w}_{\text{new}} := \vec{w}_{\text{old}} - \alpha \nabla J(\vec{w})$$
    _Де $\alpha$ — швидкість навчання (learning rate)._

**B. Аналітичне рішення: Нормальна рівність (Normal Equation):**
Це пряме, детерміноване математичне розв'язання, яке дає оптимальні ваги $\vec{w}$ за один крок. Це найбільш точний метод знаходження параметрів, якщо матриця $X^T X$ обернена:

$$\vec{w}_{\text{best}} = (X^T X)^{-1} X^T \vec{y}$$
